# c-axis misorientation

This repository contains a Dream.3D pipeline that calculates the c-axis misorientation between adjacent grains. 

The jupyter notebook "caxis_misorientation_angles.ipynb" exports a csv file with all the angles sorted in a list for easier identification of the angles of the pair of grains of interest, where hydrides are located.
