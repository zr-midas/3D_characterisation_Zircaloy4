# Basal_GB_angles

This repository contains a Dream.3D pipeline to identify the normal vector (c-axis) to the basal planes of the grains and a jupyter notebook that calculates and plots the angles between these vectors and the normal vectors to the grain boundaries planes manually fitted in Paraview.
