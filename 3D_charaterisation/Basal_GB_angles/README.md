# Basal_GB_angles

This folder contains:

- A Dream.3D pipeline to identify the normal vector to the basal planes of the grains (their c-axis)
- A Jupyter notebook that calculates and plots the angles between c-axis vectors and the normal vectors to the grain boundary planes manually fitted in Paraview.

## Input files:

- Dream3D file with the reconstructed 3D-EBSD data.
- Corresponding xdmf file for the GB plane fitting. 

## Exported files:

- Dream3D file with the c-axis vectors.
